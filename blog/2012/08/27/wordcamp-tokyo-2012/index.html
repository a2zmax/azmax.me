WordCamp Tokyo 2012 までの準備は、コレだ！

2012/8/27 WordPress

こんにちわぷー！あずまーっくす！
久々のエントリー、というか構築し直した環境での初エントリーが、
WordCamp Tokyo 2012 リレーブログというのも、なかなか乙なものですね。
今回は @Ghichi さんの ゆるやかにつながろう ♪：WordCampTokyo2012リレーブログ にバトンを受けてのエントリーです。

というわけで、9/15 に WordCamp Tokyo 2012 が開催されます。

しかも、今年は PHP Conference 2012 との同時開催となっています。
PHP Conference 2009 の時に、WordPress ブースで少しお手伝いしたことを思い出すと、感慨深いです。

WordCampって、なんだ？

WordCamp 自体の説明は WordCamp公式サイトや WorCamp Tokyo 2012公式サイトに譲るとして、
今回は、WordCamp Tokyo 2012 に参加するにあたって、事前に準備しておいた方が良いものについて、
自分の経験を振り返りながら、エントリーします。

何はともあれ、名刺

WordCamp Tokyo の定員は1,000名！
つまり、これだけの人と出会う機会があるわけです(PHP Conference も入れるともっと)。
公式ブログでも紹介されていますが、
自己紹介するためには、やはり名刺は持っていきたいところ。
会社に所属している人は、会社の名刺でも良いのですが、
自分自身を知ってもらいたいって場合もあると思うんですよね。
その場合、プライベート用の名刺を作って、持っていくと良いかもしれません。
載せるのは、名前や運営しているサイト・ブログのURL、
twitter やfacebook のアカウントなどなど。
写真も載せておくと、相手が思い出しやすいかも。

名刺といえば、今回一緒にスタッフをしている、こうめさん、こと @Bamboo_C さんが以前ブログにまとめられてましたね。
よければ、ご参考に！

「日本」のクリエイティブな名刺

名刺に載せるサイトや、SNSアカウント

名刺に名前と電話番号だけだと、ちょっと寂しいですよね。
なので、twitter や facebook のアカウントも載せちゃいましょう！
そういえば、今回は わぷーアイコンを作れるブースがある、かも？？

タイムテーブルの確認

今回のWordCamp は文化祭的なノリで企画しています。
セッションも、たくさん！盛り沢山！なんですね。
でもでも、セッションが沢山あると、どれに参加したら良いか、わからなくなるかも。
事前にタイムテーブルをチェックしておきましょう。

ノートパソコンでカタカタ

ハンズオンに参加される場合は必須ですね。
それ以外でも、セッションをメモしたり、調べものしたり。
あるいは自分で書いたコードを他の参加者に見てもらったりと、使い方は色々です。
ただ、今回のWordCamp では、セッションも短めになっていて、
移動も多くなりそう＞＜。
落下や忘れ物に、要注意！

お腹空くから、お弁当持ってくか

会場内は、ごめんなさい、お弁当を広げて食べる十分なスペースの提供が難しくなりそうです。
でも、せっかくWordCamp に来たんだから、
WordPress に興味がある人と、一緒にランチとかどうでしょう？
今回のWordCamp ではランチボードが設置される予定です。
詳しくは、WordCamp おもてなしチームブログをご覧ください。
自分もWordCamp Yokohama 2010 で経験しましたが、
SNSでの知り合い同士が集まって、ちょっとしたオフ会みたいになるかもですよ？

ライトニングトークにも参加してみる

WordCamp Tokyo 2012 の締め括りは、PHP Conference 2012 との合同のライトニングトーク(LT)です。
今回のLT 自体の説明はメガネさんが、リレーブログの二日目に、初めてのひとこそライトニングトークに参加を！：WordCampTokyo2012リレーブログで紹介されています。

合同、ということは、PHP Conference 参加の人もいるわけで、1,000人を超える人の注目を集めちゃうわけです。
これはもう、参加してアピールするしかないっ！

募集要項はこちら
http://2012.tokyo.wordcamp.org/inquiry/lt/

LightningTalkについての説明記事はこちら
http://2012.tokyo.wordcamp.org/2012/08/24/lightningtalk/

最後に

というわけで、色々と書いてきましたが、

そう、人ですよ。WordPressの強さは「人」。

という言葉に尽きると思うのです。
上の言葉は、先日、Web担当者Forum の記事で、@digitalcube 古賀さん の発言からの引用ですが、
その「人」が実際に、わーって集まるところがWordCamp。

WordPressの持つ、強さ・熱さ・すごさ、その他もろもろ、一度体験しにきませんか？

そして、明日のリレーは自分がWordPress に参加するきっかけをいただいた、
@naokomcさん です！
先日、名古屋のWordBeach に参加されたばかりですが、さてさて、どんなブログになるのでしょうか。
